# 什么值得买 (SMZDM) 好价自动化监控与推送系统

这是一个基于 GitHub Actions 驱动的纯 Serverless 监控脚本。它通过自动扫描“什么值得买”最新的商品数据，并结合强大的“互动门槛”与“水军检测”机制，精准捕捉真实的神价格商品，并通过 WxPusher 实时推送到你的微信。

## ✨ 核心特性

- 🚀 **完全 Serverless**：依赖 GitHub Actions `cron` 定时触发（默认每 10 分钟执行一次），无需购买和维护云服务器。
- 🎯 **精准漏斗过滤**：
  - **白名单机制**：自动屏蔽高赞文章和资讯，只监控“发现”、“优惠”、“海淘”等纯商品频道。
  - **时间窗口**：智能越过数据未发酵的“0互动”新商品，深入扫描 1~3 小时内的成熟数据。
  - **基础互动门槛**：必须同时满足指定的评论数、收藏数、值票数以及好评率才会触发推送。
- 🛡️ **水军防线**：独创的异常数据检测算法。如果一个商品呈现“只有值没有不值”或者“值票极高但零评论”的异常形态，将被直接拦截。
- 💾 **无感去重记忆**：采用 SQLite 配合 `actions/cache` 的高级云端接力缓存机制。即使每次运行都在全新的虚拟机上，也能完美记住过去 30 天推送过的商品，杜绝重复骚扰。
- 📱 **微信原生卡片**：对接 WxPusher，推送内容包含直观的商城标签（如【京东】）、红字醒目的价格、发布时间以及全维度的互动数据。

## ⚙️ 工作原理

1. GitHub Actions 每 10 分钟唤醒一次容器。
2. 从云端下载上一次运行结束时保存的 `smzdm.db`（SQLite数据库）至本地。
3. 按照设定的分页深度（最高 150 页），向前追溯历史发布数据，直到扫到发布时间超过 3 小时（可配）的商品停止。
4. 过滤所有命中频道的黑名单内容，计算并校验各项互动指标。
5. 发现满足严苛条件的神价，且 `smzdm.db` 中没有历史记录时，触发微信推送。
6. 推送成功后，将商品 ID 写入数据库。
7. 运行结束，GitHub Actions 将新的 `smzdm.db` 重新打包上传至云端缓存。

## 🛠️ 如何使用与配置

### 1. 准备 WxPusher 凭证
你需要前往 [WxPusher 官网](https://wxpusher.zjiecode.com/) 注册一个应用，获取以下两个参数：
- `APP_TOKEN`：应用的身份凭证。
- `UID`：你个人微信绑定的专属 UID（接收消息的人）。

### 2. 配置 GitHub Secrets
Fork 本项目后，在你的 GitHub 仓库主页，点击 `Settings` -> `Secrets and variables` -> `Actions`，添加以下两个环境变量：
- `WXPUSHER_APP_TOKEN` = (填入你获取的 APP_TOKEN)
- `WXPUSHER_UID` = (填入你获取的 UID)

### 3. 个性化调整阈值
你可以直接修改 `smzdm.py` 中的全局 `CONFIG` 字典，定制属于你自己的过滤强度：

```python
CONFIG = {
    "max_history_hours": 3,             # 追溯的最大时长，默认深潜 3 小时
    "blacklist_channels": ["文章", "资讯", "社区", "晒物"], # 黑名单过滤

    "min_comments": 5,                  # 最小评论数
    "min_collection": 5,                # 最小收藏数
    "min_worthy": 5,                    # 最小“值”票数
    "min_score_rate": 70,               # 最低好评率（%）
    
    # 水军检测相关...
}
```

## 📝 运行日志

你可以随时在 GitHub 仓库的 `Actions` 面板中查看每一次运行的详细日志。日志格式清晰，会展示被过滤、跳过以及成功推送的详细统计。
