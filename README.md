# 什么值得买 (SMZDM) 高级监控推送系统 v2.0

这是一个基于 GitHub Actions 的 **Serverless 级**深度监控系统。它抓取什么值得买好价列表，结合综合互动评分、京东自营校验、评论用户等级和互动异常分析，筛选出更可靠的好价。

## 🚀 v2.0 核心黑科技

### 1. 智能加权评分模型 (Weighted Scoring)
不再采用死板的单一数值门槛，而是通过加权算法评估商品热度：
- **公式**：`综合评分 = 💬评论×3 + ⭐收藏×2 + 👍值×1`
- **逻辑**：大幅提升了“评论”的权重，因为评论成本最高、最难造假，是真实热度最硬核的指标。
- **多路径放行**：均衡热度、高讨论、早期好价分别使用不同阈值，避免一个硬阈值错过真实好价。

### 2. 真实评论等级水军拦截 (Anti-Shill Engine)
对高分候选商品调用 SMZDM 移动端详情模块：
- **用户等级分析**：从 `user_related_modul` 返回的评论 JSON 中读取 `vip_level`。
- **低等级拦截**：Lv5 及以下视为低等级账号；若低等级评论用户占比超过 50%，直接拦截不推送。
- **可用性兜底**：评论等级接口不可用或可取评论数不足时，不硬判水军，继续走互动异常兜底。

### 3. 京东自营校验
京东渠道只放行自营商品：
- 从频道接口回查 `article_link`。
- 解析 SMZDM `go.smzdm.com` 跳转到京东商品页。
- 读取京东商品页真实 `isSelf:true/false` 字段；非自营或无法确认时默认过滤。

### 4. 分阶段漏斗过滤
1.  **API 初筛**：基于多路径加权评分模型，快速剔除平庸信息和纯活动券。
2.  **相似去重**：用商品标题指纹过滤 3 天内重复爆料。
3.  **真实性验证**：京东自营校验 + 评论区用户等级检测。
4.  **数据分析比对**：计算 值/不值 比、评论/值 比，进行数据异常兜底检测。

### 5. 反爬稳定性保护
- 京东自营和评论等级属于详情/跳转类请求，单轮运行有请求预算上限。
- 详情/跳转类请求之间加入随机慢速间隔，避免短时间连续访问。
- 如果返回 `202/403/429`、`probe.js`、验证码或访问频繁标记，本轮立即熔断外部校验。
- 熔断后不再继续请求详情页或跳转页，防止 workflow 继续撞反爬。

## 📊 现行推送标准 (CONFIG)

| 路径 | 门槛要求 | 说明 |
| :--- | :--- | :--- |
| **均衡热度** | 评论+收藏+值 ≥ 15，综合评分 ≥ 45，好评率 ≥ 70% | 正常热门好价 |
| **高讨论** | 评论 ≥ 8，互动 ≥ 20，综合评分 ≥ 70，好评率 ≥ 55% | 有争议但真实用户讨论充分的好价 |
| **早期好价** | 值 ≥ 4，互动 ≥ 8，综合评分 ≥ 18，好评率 ≥ 85% | 低评论但值票增长快的早期好价 |
| **基础信号** | 值 ≥ 2 或评论 ≥ 2 | 过滤纯收藏、纯活动券 |
| **发布时间** | 过去 6 小时内 | 给商品充分的发酵时间 |
| **京东自营校验** | 每轮最多 5 条 | 超额或无法确认时默认不推京东商品 |
| **评论等级校验** | 每轮最多 8 条 | 超额或熔断时跳过等级判断，回落到互动异常兜底 |

## 🛠️ 部署指南

1. **配置 Secrets**: 在 GitHub 仓库设置中添加 `WXPUSHER_APP_TOKEN` 和 `WXPUSHER_UID`。
2. **环境要求**: 安装 `requirements.txt` 中的依赖即可。
