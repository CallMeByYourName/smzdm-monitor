# 什么值得买 (SMZDM) 高级监控推送系统 v2.0

这是一个基于 GitHub Actions + Playwright 驱动的 **Serverless 级**深度监控系统。它不仅能抓取好价，更能通过“人类行为学分析”识别并拦截水军刷单，为你筛选出真正值得买的硬核好价。

## 🚀 v2.0 核心黑科技

### 1. 智能加权评分模型 (Weighted Scoring)
不再采用死板的单一数值门槛，而是通过加权算法评估商品热度：
- **公式**：`综合评分 = 💬评论×3 + ⭐收藏×2 + 👍值×1`
- **逻辑**：大幅提升了“评论”的权重，因为评论成本最高、最难造假，是真实热度最硬核的指标。

### 2. Playwright 级水军拦截 (Anti-Shill Engine)
引入自动化浏览器引擎，对高分候选商品进行“深度背景调查”：
- **用户等级分析**：自动爬取评论区，分析所有发言用户的等级。
- **降维打击**：若 Lv6 以下的低等级用户占比超过 50%，系统将判定为“水军围攻”，直接拦截不予推送。
- **语义折叠识别**：若 API 显示有评论但网页端全部被官方系统折叠，识别为潜在刷单信号。

### 3. 三阶段漏斗过滤
1.  **API 初筛**：基于加权评分模型，快速剔除平庸信息。
2.  **真实性验证**：启动 Playwright 引擎，执行评论区等级检测。
3.  **数据分析比对**：计算 值/不值 比、评论/值 比，进行数据异常兜底检测。

## 📊 现行推送标准 (CONFIG)

| 指标 | 门槛要求 | 说明 |
| :--- | :--- | :--- |
| **基础活跃度** | 评论 + 收藏 + 值 ≥ 15 | 确保不是无人问津的冷门贴 |
| **综合评分** | ≥ 40 | `评论*3 + 收藏*2 + 值*1` 达标 |
| **好评率** | ≥ 70% | 群众的眼睛是雪亮的 |
| **发布时间** | 过去 6 小时内 | 给商品充分的发酵时间 |

## 🛠️ 部署指南

1. **配置 Secrets**: 在 GitHub 仓库设置中添加 `WXPUSHER_APP_TOKEN` 和 `WXPUSHER_UID`。
2. **环境要求**: 本项目需要安装 `playwright` 及其浏览器内核（见 workflow 配置）。
